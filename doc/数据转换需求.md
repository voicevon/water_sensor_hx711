# HX711 数据转换 uint16 无符号方案需求

## 背景

HX711 输出 24 位有符号原始值。系统用途为水位检测，不换算物理重量。系统内部计算与对外传输（MQTT、BLE、Web）全部以 16 位无符号数为基准，采集后立即完成转换，后续环节不再出现有符号数与浮点克力值。

## 功能需求

### 1. 数据转换规则
- 转换仅两步：以 32 位有符号中间值 X 承接，X = 原始 24 位有符号值 + 2^K；再将 X 右移 N 位，得到 16 位无符号数。
- K 与 N 的绑定关系：基线居中要求 2^K 右移 N 位后落在 16 位量程中部，即 K = N + 15。N 是唯一独立参数，K 由 N 导出，不单独存储。
- 范围依据（机械现实事先未知，不设数值性硬界）：
  - 空载零偏（零点不平衡 + 零点漂移 + 安装因素）围绕 0 上下浮动，浮动范围未知。
  - 负载上限存在但数值未知（可能 100 g、200 g、1 kg 等），额定约 1 吨；实际负载仅占额定量程的几分之一（如 1/8、1/16、1/128），安装确定后不变。
  - 因此 N 的合适值取决于现场机械状态，无法离线确定（可能右移 2 最好，也可能右移 5 最好），必须现场调定。
- N 配置：NVS 可配置项，合法范围 0~8，默认 6；非法写入拒绝，非法读出回退默认。上下限含义：N = 0 为精度上限（1 LSB = 1 原始计数，窗口 ±2^15），N = 8 为精度下限（1 LSB = 256 原始计数，窗口覆盖芯片全输出范围）；全范围合法，选择是否恰当由运行时自检与现场观察判定。
- 分辨率：1 LSB = 2^N 原始计数，N 越小精度越高；N 即"最高精度"与"覆盖窗口 ±2^(N+15) 须罩住实际零偏与负载"之间的现场权衡。
- 覆盖窗口：u16 结果对应原始值窗口 ±2^(N+15)，必须罩住实际零偏与满载信号；是否罩住由现场实测判断（基线与加水后读数均远离量程两端为正常）。
- 生效方式：N 修改后重启生效，阈值类参数恢复默认、需现场重新标定。
- 启动自检：启动读取若干样本，基线超出 8192~57344 时串口告警（提示当前 N 与实际零偏不匹配，需现场调整）。
- 不做去皮、不做偏置扣除：空载基线由算术自然落在量程中部附近，具体位置无需关心，由后期算法基线跟踪自行修正。

### 2. 基线定位
- 基线位置不作为系统约定：名义基线 32768，实际基线 = 32768 + 零偏 / 2^N，随 N 减小摆动增大；合适与否由启动自检与现场观察判定，不依赖事先数值假设。
- 越界性质：仅 N = 8 时芯片全输出范围映射不越界；N < 8 时窗口为 ±2^(N+15)，实际零偏越过窗口下缘则结果回绕，由启动自检告警提示 N 选择不当。

### 3. 去皮
- 无去皮功能（自动或人工均无）。上电时传感器上可能有残水或负载，任何"启动时标零"都会引入错误零点。

### 4. 删除校准功能
- 删除 scale（克数换算系数）校准：设置接口、NVS 存储键、网页校准入口全部移除。
- 删除人工去皮功能及其网页入口。
- HX711 读取直接取 24 位原始值，不经过任何克数换算与偏置扣除。

### 5. 全链路无符号
- Sensor 三套算法（DYNAMIC / DISCRETE / ENVELOPE）输入输出均为 16 位无符号原始计数。
- MQTT、BLE、Web 上报值为 16 位无符号原始计数。

### 6. NVS 参数版本管理
- 参数存储结构增加版本号；移位位数 N 存于 NVS（仅存 N，K 由 K = N + 15 导出）。
- 检测到旧版本参数时重置为默认值；阈值类参数需现场重新标定。
- N 的写入需校验合法范围 0~8，非法值拒绝；读出非法值时回退默认 6。

## 对外影响

- 上报值语义由“0.1g 单位”变为“缩放后原始计数”（1 LSB = 2^N 原始计数，空载约 32768 附近），上报报文（MQTT/BLE）格式保持不变、不携带 N（2026-09-21 用户明确否决，协议不变更）；N 仅通过 Web 页面与 /api/hx711 查询，订阅端需另行约定；Android 等订阅端需同步适配。

## 实施步骤

1. 配置文件：新增两步转换函数（X = 原始值 + 2^K、右移 N 位；K = N + 15 运行时导出），废弃原克数转换函数。
2. 传感器驱动：读取接口改为输出 16 位无符号数组，直接取 24 位原始值；删除 scale 设置接口与去皮接口。
3. NVS 配置：删除 scale 与 tare 相关存取；新增 N 的存取与合法性校验（0~8，默认 6）；增加参数版本号与旧数据重置逻辑；N 变更视为版本变更，阈值恢复默认。
4. 主程序：数据流全程 16 位无符号贯通，删除浮点克力中转，串口日志列名同步；启动自检基线位置并告警。
5. Web 缓存与页面：raw_val 字段语义改为缩放后原始计数；新增 N 设置项（0~8，重启生效）；删除 scale 校准与手动去皮 UI。
6. 编译、烧录、串口验证：各 N 档位下空载基线位置、加水变化方向与幅度、三套算法触发正常。
